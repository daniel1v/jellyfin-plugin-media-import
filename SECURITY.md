# Security policy

## Supported versions

Media Import is currently beta software. Security fixes are provided for the latest published beta only.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** function in the repository's Security tab. Do not include API keys, access tokens, real media paths, media files, or other private server data in a public issue.

For ordinary bugs that do not contain sensitive information, use the public issue tracker and include the Jellyfin version, plugin version, operating system, reproduction steps, and relevant sanitized log lines.
